## Findings (non-VERIFIED items)

### 1. AMBIGUOUS — PAR permission wording drift ("MAY use" vs "MAY consider using"; RFC 6749 qualifier dropped in one occurrence)

Extraction claims (2 occurrences):
- Line 62–63: "Implementers MAY use pushed authorization requests (RFC 9126) (§3)."
- Line 146: "Implementers MAY use pushed authorization requests (RFC 9126) for authorization requests (§3)."

Source (§3):
> "In case of authorization requests as defined in [RFC6749], implementers MAY consider using pushed authorization requests [RFC9126] to improve the security, privacy, and reliability of the flow."

Verdict: AMBIGUOUS. The normative phrase is "MAY consider using", not "MAY use"; practically both grant the same permission, so this is a wording drift, not a level shift. The first occurrence also drops the qualifier "In case of authorization requests as defined in [RFC6749]" (the second occurrence partially restores it with "for authorization requests"). No reader would be misled into a wrong implementation, but the paraphrase is not exact.
